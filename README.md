# THE GROOVE MIXER (Android APK)

Upload ang lahat ng files sa repo (kasama ang `.github/workflows/build-apk.yml`).
Actions > Build APK > Run workflow > i-download ang `THE-GROOVE-MIXER-apk` sa Artifacts > i-install ang `THE-GROOVE-MIXER.apk`.
Optional: idagdag ang sarili mong `lame.min.js` sa tabi ng `index.html`.
